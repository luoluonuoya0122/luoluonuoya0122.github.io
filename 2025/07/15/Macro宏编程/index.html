Macro宏编程

发表于2025-07-15|更新于2025-07-18
|阅读量:

声明宏

声明宏（Declarative Macros），也称为macro_rules!，是最常⻅的宏类型。它们允许通过模式匹配来⽣成代码

过程宏

过程宏允许你使用函数生成代码，它们分为三种类型：

  • 派生宏，可以为目标结构体或枚举派生指定的代码，例如 Debug 特征
  • 属性宏，用于为目标添加自定义的属性
  • 函数宏，看上去就像是函数调用

派生宏示例

Debug
自动实现 std::fmt::Debug trait，用于打印调试信息。

Clone和Copy

  • Clone：允许显式克隆（调用 .clone() 方法）。
  • Copy：允许隐式按位复制（通常用于简单类型）。 PartialEq和Eq
  • PartialEq：实现部分相等比较（== 和 !=）。
  • Eq：标记类型满足完全等价关系（无额外逻辑，需与 PartialEq 一起派生） PartialOrd和Ord
  • PartialOrd：实现部分排序（<、>、<=、>=）。
  • Ord：实现全序排序（需与 PartialOrd 和 Eq 一起派生）。 Hash
    实现 std::hash::Hash，允许类型作为哈希表的键。 Default
    自动实现 Default trait，提供默认值。

属性宏示例

#[derive]
虽然不是传统意义上的属性宏（它是派生宏），但语法上是属性形式，用于自动实现 trait。

#[cfg]
条件编译，根据目标平台或特性决定是否包含代码。

#[allow] / #[warn] / #[deny] / #[forbid]
控制编译器警告或错误。

总结

  • 创建声明宏：使用marco_rules定义宏，通过模式匹配生成代码
  • 创建过程宏：使用过程宏派生宏和属性宏生成代码

宏的应用场景

  • 减少重复代码：通过宏生成重复的代码
  • 编译器计算：在编译器进行计算并生成代码，提高运行时性能
  • DSL：使用宏定义领域特定语言，提高代码的表达力和可读性
